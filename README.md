# CODSOFT – Python Programming Projects

## About the Repository

This repository contains Python projects developed as part of my **CODSOFT Python Programming Internship**.

The projects focus on applying Python programming fundamentals, developing problem-solving skills, and building simple interactive applications using Python.

## Projects Included

### 1. Simple Calculator
A graphical calculator developed using Python and Tkinter.

**Features:**
- Performs basic arithmetic operations.
- Supports addition, subtraction, multiplication, and division.
- Provides a clear button to reset calculations.
- Interactive graphical user interface.

**File:** `calculator.py`

### 2. Password Generator
A graphical password generator that creates passwords based on the selected length and strength.

**Features:**
- Generates passwords of different lengths.
- Provides multiple password strength options.
- Uses random character selection.
- Includes a graphical interface.

**File:** `password generator.py`

### 3. Rock Paper Scissors
A Python implementation of the classic Rock Paper Scissors game.

**File:** `rock paper scisssor.py`

## Technologies Used

- Python
- Tkinter
- Random Module

## Installation and Execution

### Prerequisites
- Python 3.x installed on your system.

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/MeghanaNagidi/codsoft.git
   ```

2. Navigate to the project directory:

   ```bash
   cd codsoft
   ```

3. Run any project using Python:

   **Calculator**
   ```bash
   python calculator.py
   ```

   **Password Generator**
   ```bash
   python "password generator.py"
   ```

   **Rock Paper Scissors**
   ```bash
   python "rock paper scisssor.py"
   ```
